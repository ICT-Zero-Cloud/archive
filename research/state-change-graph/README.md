# CloudTrail 관측 공백 환경에서 AWS 인프라 상태 변화 기반 그래프 추적 모델

2026년 한국정보보호학회 동계학술대회 CISC-W’26 / 구두발표

저자: 강인석, 서장훈, 정준식, 박기웅

## 연구 내용

CloudTrail 기록이 없는 구간에서 사고 전후의 인프라 상태 차이를 비교하고, 변경 흔적의 연관 관계를 그래프로 구성합니다.
